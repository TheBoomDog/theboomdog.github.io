# NovelHub catalog architecture

Novel information now has **one source of truth**: a book record plus its
ordered `chapters` array.

- `data/books.js` contains ordinary hand-maintained book records.
- `data/malfoid.js` is automatically generated by
  `scripts/import_malfoid.py`; never edit it manually.
- The shared `js/library.js` renders the homepage, browse, search, rankings
  (by real chapter count), and chapter updates.
- `js/book.js` renders any `book.html?id=<id>` using those same records.
- `js/reader.js` displays the chapter linked from the record.
- `css/site.css` defines shared library styling.
- Both catalogs are loaded before the renderer; no page contains embedded novel
  cards, genre options, or hand-selected recent-chapter links.

## Add another novel

Add an entry to `data/books.js` (or generate a separate data script and load
it before the scripts on library/book/reader pages). Example:

```js
{
  id: "your-unique-id",
  title: "Your Novel",
  author: "Author",
  status: "In progress",
  genres: ["Fantasy"],
  description: "A short book description.",
  cover: { start: "#455744", end: "#15241f", ink: "#e5cc9f" },
  chapters: [
    {
      key: "book-1-chapter-01",
      label: "Chapter 1",
      title: "The Opening",
      href: "reader.html?id=your-unique-id&chapter=book-1-chapter-01",
      source: "Novels/Your_Novel/chapter_1.html",
      updatedAt: "2026-10-24T10:45:00Z"
    }
  ]
}
```

For manually added books, the `key` property is optional, but strongly
recommended to keep chapter links and progress stable if chapters are inserted.
The `source` file must contain a `.chapter-content` container. A `format:
"jekyll"` record can use the entire rendered Markdown document body instead.

**Use real dates only.** `updatedAt` is optional: undated legacy chapters
are displayed after dated updates, without invented publication dates.

For Malfoid, the publishing workflow reads each chapter's last Git commit date
from the private source repository and generates its `updatedAt` automatically.
The workflow checks for changes twice hourly. It imports only volumes explicitly
approved through the `MALFOID_APPROVED_BOOKS` variable.

## What comes from the catalog

The shared renderer automatically determines:

- Listing cards, statuses and chapter counts
- Genre options, filters, sorting and chapter-count rankings
- Latest updated chapters and the searchable complete chapter updates page
- Book cover colors, descriptions, labels and chapter navigation
- Save and Continue Reading links

The saved-novel and reading-progress keys are unchanged, so existing reader
preferences and saved books are preserved.
