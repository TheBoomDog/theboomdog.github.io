Privacy & source code

TL;DR: NovelHub's website code is publicly available on GitHub. We use GoatCounter to count anonymous visits to each novel for weekly rankings, with statistics set to a 31-day retention period. We do not collect reading histories, require accounts, run ads, or build profiles of readers.

Exactly what we count

When you open a chapter, our site sends a small request to GoatCounter identifying only the novel, such as /novel/example. We don't include which chapter you opened, your reading position, a referral URL, or screen-size details. GoatCounter's statistics retention is configured for 31 days. We use the counts to calculate the weekly top ten, but publish only ranking positions, not visit totals.

Anonymous does not mean that no network information is transmitted. GoatCounter receives ordinary request information such as your IP address and browser's User-Agent. According to GoatCounter's privacy documentation, it does not save IP addresses or full User-Agent headers to its database; it can use them temporarily in memory for up to eight hours to avoid counting repeat visits. The analytics request uses no tracking cookies or persistent identifier.

Your reading data stays on your device

Saved books, chapter progress and scroll position, reading preferences, and New/Updated chapter indicators are stored locally in your browser. We cannot see this information and do not send it to an account or sync it between devices. Clearing the site's browser storage removes this reading history.

Other services involved

GitHub Pages hosts the website. Like other hosting services, it handles ordinary requests to deliver the pages; its infrastructure and logging are governed by GitHub's own policies, not our 31-day GoatCounter setting. Readers may also block the GoatCounter request with browser privacy tools, which can make our counts less accurate.

Our Report a problem links open public GitHub issues. Filing a report requires a GitHub account, and the text you choose to submit is public. No locally saved reading progress is automatically included.

Read the source code

The source for NovelHub's website, including its reader, catalog, and anonymous visit-counting implementation, is publicly viewable on GitHub. You can inspect exactly what the site's own scripts do.

Publicly available isn't the same as open-source licensed. The repository does not currently contain a software license granting reuse rights. The hosted novels and other literary works are also not being offered for unrestricted reuse.
