Privacy & source code

The short version: You don't need an account to read. NovelHub does not use advertising cookies, collect reading histories, or build reader profiles. Your bookmarks, reading position, and chapter-read indicators stay on your own device. The site's code is publicly available to inspect.

One exception: anonymous visit counts

NovelHub currently uses GoatCounter to count visits to a novel's reader, solely for the weekly popularity rankings. We send an anonymous request identifying which novel was opened—not the chapter, your reading position, your name, or a user account. We do not send referral-page or screen-size analytics.

This is still a form of visit counting, not literally zero tracking. Like any remote service, GoatCounter necessarily receives ordinary network information such as your IP address and browser headers when the request is made. The public site only displays ranking positions, not visit totals. Browser privacy tools may block the counter.

What stays in your browser

Saved novels, your last-read chapter and scroll position, reading settings, and New/Updated chapter status use your browser's local storage. NovelHub does not upload that information or sync it between devices. Clearing your browser's site data clears it, and another device starts without that history.

Public source code

NovelHub is built as a static GitHub Pages site, and its website files can be read on GitHub. You can inspect the code behind the reader, catalog, visit-counting and publishing features. The repository does not currently include an open-source license, so publicly viewable source should not be mistaken for blanket permission to reuse it.

The novels and other third-party literary material are separate from the website software. Their presence in a public repository does not grant permission to republish or relicense them.
